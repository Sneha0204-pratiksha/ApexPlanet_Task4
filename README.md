# ApexPlanet_Task4
A responsive multi-page portfolio website by Sneha Patil featuring interactive To-Do List (with localStorage) and Product Listing Page (with filtering and sorting). Built using HTML, CSS, and JavaScript.
## 🎯 Objective
Combine **HTML**, **CSS**, and **JavaScript** to build fully functioning and interactive web projects.

This project demonstrates all major front-end development concepts — responsiveness, interactivity, local storage, filtering, sorting, and smooth UI design — through a complete portfolio website and two mini web apps.

---

## 🧩 Project Overview

### 🔹 1. Personal Portfolio Website
A professional **multi-page portfolio** showcasing my skills, projects, and contact details.

**Features:**
- Fully responsive design with a modern neon-glow theme.  
- Typewriter effect and smooth transitions.  
- Sections: **Home**, **Projects**, and **Contact**.  
- Interactive navigation and footer.  

**Files:**
- `index.html` – Home page  
- `projects.html` – My project showcase  
- `contact.html` – Contact form and social links  

---

### 🔹 2. To-Do List App with Local Storage
An interactive to-do list that stores user tasks even after refreshing the page.

**Features:**
- Add and delete tasks dynamically.  
- Persistent data using **localStorage**.  
- Sleek, glowing button effects and smooth hover animations.  
- Responsive layout for mobile and desktop.  

**File:** `todo.html`

---

### 🔹 3. Product Listing Page with Filtering & Sorting
A dynamic product page that allows users to explore items easily.

**Features:**
- **Filter** products by category.  
- **Sort** products by price.  
- Responsive product grid using CSS Flexbox.  
- Real-time updates using JavaScript DOM manipulation.  

**File:** `products.html`

---

## ⚙️ Technologies Used
- **HTML5** – Structure and semantics  
- **CSS3** – Styling, animations, and responsiveness  
- **JavaScript (ES6)** – Logic, interactivity, and localStorage
